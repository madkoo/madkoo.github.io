# Assets Directory

This directory is for storing images, icons, and other static assets for the personal profile site.

## Recommended Assets

You can add the following files to enhance your profile site:

- **profile-photo.jpg**: Your professional headshot (recommended: 400x400px)
- **favicon.ico**: Browser favicon
- **icons/**: Directory for any custom icons or logos

## Usage

To use images in your site, reference them in `index.html`:

```html
<img src="assets/profile-photo.jpg" alt="Madis Koosaar">
```

## Image Optimization

For best performance:
- Use WebP format for photos when possible
- Optimize images before uploading
- Keep file sizes under 500KB for photos
- Use SVG for logos and icons when possible
